# RESQ-AI Exploratory Data Analysis & Notebooks

This directory is designated for interactive exploratory data analysis (EDA), visualization experiments, and prototype testing once datasets are provided.

## Notebook Guidelines
1. Raw datasets in `data/raw/` must NEVER be modified directly from notebooks.
2. Notebooks should be structured by dataset inspection or pipeline stage (e.g., `01_imd_eda.ipynb`, `02_gfsm_eda.ipynb`).
3. Standard model training scripts should be migrated to `training/scripts/` once validated.
